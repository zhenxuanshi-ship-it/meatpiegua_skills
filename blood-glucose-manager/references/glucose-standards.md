# 血糖医学判断标准参考

## 一、世界卫生组织(WHO)标准

### 1. 糖尿病诊断标准

| 检测项目 | 正常 | 糖尿病前期 | 糖尿病 |
|---------|------|-----------|--------|
| 空腹血糖(FPG) | < 6.1 mmol/L | 6.1 - 6.9 mmol/L | ≥ 7.0 mmol/L |
| 餐后2小时血糖(2hPG) | < 7.8 mmol/L | 7.8 - 11.0 mmol/L | ≥ 11.1 mmol/L |
| 随机血糖 | < 11.1 mmol/L | - | ≥ 11.1 mmol/L |
| 糖化血红蛋白(HbA1c) | < 5.7% | 5.7% - 6.4% | ≥ 6.5% |

### 2. 说明
- **空腹**：至少8小时未进食（可饮水）
- **餐后2小时**：从进食第一口开始计时
- **随机**：任意时间，无论上一次进食时间

## 二、妊娠期糖尿病(GDM)标准

妊娠期标准更严格：

| 检测时间 | 正常范围 | 异常 |
|---------|---------|------|
| 空腹 | < 5.1 mmol/L | ≥ 5.1 mmol/L |
| 餐后1小时 | < 10.0 mmol/L | ≥ 10.0 mmol/L |
| 餐后2小时 | < 8.5 mmol/L | ≥ 8.5 mmol/L |

**诊断标准**：任意一项达到或超过阈值即可诊断GDM

## 三、血糖控制目标（糖尿病患者）

### 1. 一般成人目标（中国2型糖尿病防治指南）

| 指标 | 理想 | 一般 | 差 |
|------|------|------|-----|
| 空腹/餐前 | 4.4-6.1 | ≤ 7.0 | > 7.0 |
| 餐后2小时 | 4.4-8.0 | ≤ 10.0 | > 10.0 |
| 糖化血红蛋白 | < 6.5% | < 7.0% | ≥ 7.0% |

### 2. 特殊人群

**老年人（>65岁）**：
- 空腹：5.0-7.2 mmol/L
- 餐后2小时：5.0-10.0 mmol/L
- HbA1c：< 7.5-8.0%

**青少年儿童**：
- 空腹：4.4-7.0 mmol/L
- 餐后2小时：5.0-10.0 mmol/L
- HbA1c：< 7.5%

**妊娠期**：
- 空腹：3.3-5.3 mmol/L
- 餐后1小时：5.3-7.8 mmol/L
- 餐后2小时：4.4-6.7 mmol/L

## 四、低血糖标准

| 分级 | 血糖水平 | 症状 |
|------|---------|------|
| 轻度 | 3.0-3.9 mmol/L | 出汗、饥饿、心悸 |
| 中度 | < 3.0 mmol/L | 认知障碍、行为改变 |
| 重度 | < 2.2 mmol/L | 意识丧失、抽搐 |

**注意**：糖尿病患者< 3.9 mmol/L即为低血糖

## 五、健康建议

### 1. 空腹血糖偏高
- 睡前避免加餐
- 检查晚餐碳水化合物摄入量
- 关注睡眠质量
- 黎明现象需就医调整用药

### 2. 餐后血糖偏高
- 控制主食量，粗细搭配
- 调整进餐顺序：蔬菜→蛋白质→主食
- 餐后30分钟适当运动
- 避免餐后立即休息

### 3. 血糖波动大
- 规律进餐时间
- 避免高糖食物
- 增加膳食纤维
- 监测记录寻找规律

### 4. 何时就医
- 空腹持续≥7.0 mmol/L
- 随机血糖≥11.1 mmol/L
- 频繁低血糖（<3.9）
- 出现多饮、多尿、体重下降等症状

## 六、血糖测量注意事项

### 1. 空腹血糖
- 空腹8-12小时
- 晨起后尽快测量
- 测量前避免剧烈运动

### 2. 餐后血糖
- 计时从进食第一口开始
- 严格控制2小时时间点
- 保持日常饮食和活动习惯

### 3. 随机血糖
- 任意时间点
- 记录测量时的状态（餐后多久、有无运动等）

### 4. 测量准确性
- 定期校准血糖仪
- 确保采血充分
- 试纸在有效期内
- 手部清洁干燥

## 七、单位换算

- **mmol/L × 18 = mg/dL**
- **mg/dL ÷ 18 = mmol/L**

**常见换算**：
- 6.1 mmol/L = 110 mg/dL
- 7.0 mmol/L = 126 mg/dL
- 11.1 mmol/L = 200 mg/dL
