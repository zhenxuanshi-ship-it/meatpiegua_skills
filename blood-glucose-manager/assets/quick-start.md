# 血糖管理助手使用说明

## 快速开始

### 1. 录入血糖

**基本格式**：
```
血糖 [数值]
空腹血糖 [数值]
餐后血糖 [数值]
```

**示例**：
```
血糖6.5
空腹血糖7.2
晚餐后两小时8.8
早上空腹5.6
```

### 2. 查看统计

```
查看本周血糖
最近7天血糖
血糖统计
```

### 3. 生成报告

```
生成本周血糖报告
本月血糖月报
```

### 4. 设置提醒

首次使用需要设置定时提醒，请说：
```
帮我设置血糖测量提醒
```

我会生成cron配置，你复制后使用cron工具添加即可。

## 血糖判断标准

| 类型 | 正常 | 偏高 | 异常 |
|------|------|------|------|
| 空腹 | < 6.1 | 6.1-7.0 | ≥ 7.0 |
| 餐后2h | < 7.8 | 7.8-11.1 | ≥ 11.1 |
| 随机 | < 11.1 | - | ≥ 11.1 |

## 数据存储

血糖数据存储在：`~/.openclaw/workspace/blood-glucose/data.jsonl`

建议定期备份此文件。
