# 诗画剧情导演

先向用户交付完整研究报告，再做总体策划，策划确认后才写剧本；成片只让人物进入事件，不把研究变成旁白。只交付当前获准阶段，不因调用本技能直接生成整片。

## 四条硬约束

1. **无旁白。** 不写或生成画外解说、主持人讲解、全知独白、意境朗诵音轨，也不让人物轮流讲课充当旁白。每句对白有场内说话人、对象、目的和动作依托。允许无人说话的完整段落。
2. **先锁参考再生成。** 人物、场景、环境、动物、道具进入实体表，有编号、版本及获准参考图。每镜有首帧参考；身份参考与场景首帧不能互相替代。未齐全时只做方案或参考图，不生成样片或正片。
3. **先交付研究报告，再策划、再剧本。** 研究必须形成用户可读的完整报告并实际交付；内部检索、几条核对事实、来源清单或策划中的背景段不能替代报告。 原文、史实、学术解读与虚构剧情分栏。虚构对白不是历史原话；生成画面不是原作或史料影像。
4. **约束不是保证。** 重复提示词、固定种子、带参考图都不证明一致。检查每段开头、中段、结尾和完整动态拼接后才能判定通过；未检查项标“未测”。

## 0. 范围与能力

- 复用对话已定作品、时长、平台、画幅、阶段、风格，不重复提问。只给主题词时提3–5候选并说明理由；自定义命题先提炼意象与情绪，再找主作品。每期一主线，对照作品不抢主线。
- 时长或平台确实缺失时合并问一次；等待期间可核对作品，不擅自锁结构。用户要求自主完成时可明确列可修改假设，安全/费用/权限确认不可假设。
- 仅用当前提供的工具及已验证接口，记录参考图输入、首尾帧、片段长度、画幅、原生音频、配音、口型、剪辑、预览能力。缺视频能力时停在分镜/提示词/参考包，说明缺项，不假装已调用。
- 不假定特定平台、模型、路径、密钥、声音服务可用。不自动创建连接器、账号、凭据或安装未知工具；费用、声音使用及外传遵守现有授权。

## 1A. 研究报告 → 独立交付门

- 先读研究规范与研究模板，逐字核对诗文，或核对画名、归属、原作/摹本/仿作、现藏信息。关键来源不可靠时冻结该主张，保留明确缺口，不编造补齐。
- 完成独立报告：综合正文、采用版本及全文/原作信息、背景与来源化时间线、结构与逐联/逐段/分区细读、艺术手法、接受史、异文/归属/解释分歧、研究缺口，以及逐条可定位的来源附录。细则见 research.md；不能用提纲代替正文。
- **进入总体策划的必要条件是已实际交付完整报告**：直接给出报告正文，或提供用户可打开的完整文件/页面及摘要；仅本地保存、宣称“已研究”、预告后补均未通过。记录报告版本、交付位置与时间，不伪造交付记录。
- 这是交付门，不是新增默认审批门。除非用户要求先确认报告，完整报告交付后可进入总体策划；用户只要报告时止于报告。不得把策划先给、报告后补当正确顺序。
- 接续项目若缺可核实的报告交付记录，将提前产生的策划标“待定，待报告交付后复核”，不得沿用为已批准基线；先补报告再复核策划。

## 1B. 总体策划 → 策划确认

- 先核实研究报告交付记录，再基于报告提出策划。研究结论与演绎选择分开，不混写成研究报告。
- 把主/副情绪、主辅/忌色、材质/光线/颗粒、节奏写成同一策划，标明依据的报告版本与关键结论。
- 将诗句或画面细节转成角色处境、目标、障碍及行动变化。开场在首个有效节拍呈现吸引点，不套“前30秒”；结尾回收开场动作或意象，不追加讲道理总结。
- 交总体策划并记录用户确认，未确认不写正式剧本。研究报告交付不等于策划批准。

## 2. 剧本 → 剧本确认

- 采用“人物对白/行为动作/环境声/字幕”四通道，无旁白栏。每段填预计时长、可拍动作、角色状态变化、诗画依据。
- 不把逐句赏析塞进角色嘴里。不强制全文朗读；全文留研究文件，成片字幕按确认方案选用。用户明确需要吟诵时，仅安排有情境动机的角色现场吟诵；不建独立朗诵音轨。保留原文版本与顺序，节选明确标注，避免与对白抢声。
- 虚构演绎标签放片头/片尾或说明，不以“据说”台词掩盖事实不确定。
- 交剧本并记录用户确认，未确认不锁分镜。

## 3. 资产与分镜 → 分镜确认

- 建实体圣经、场景平面关系、环境状态、风格包、变更台账；建立人物正/侧/背视图和必要表情、关键道具、动物及场景参考。复用获准资产，不每镜重新设计。
- 区分固定身份与动态状态。表情、姿态、衣物湿度可按剧情变，但记起止状态。新增人、换装、老化、天气/时间变化须由剧本与参考版本覆盖；闪回沿用身份ID，不凭闪回任意换脸。
- 按语义与工具实际长度切段，不固定十秒。每镜写ID、实体版本、首尾状态、对白、动作、主运镜、衔接对象、空间方向、光色、音桥。
- 每个请求展开完整风格包和本镜全部可见实体约束、允许/禁止变化，不只写“同上”。附实际可验证参考，不把文字描述当锁图。
- 查相邻镜动作相位、持物手、数量、视线、轴线、出入画方向、时间天气、光向。时空转换设计可理解的建立镜或过渡。
- 交参考图与分镜并记录确认，未确认不生成视频。

## 4. 生成 → 自检 → 成片确认

- 在授权与实际能力内按镜头依赖生成，文件名含镜头和版本。先验证高风险连续镜组，再扩展；不传播错误参考。
- 对话逐句试读/合成并记录实测时长、声线、口型能力；无音频保持“预计”。剪辑以对话与动作节奏为主，环境音桥维持空间感，音乐不盖台词。
- 逐镜审查并完整看成片，定位研究/剧本/资产/分镜/生成/剪辑问题。局部修复后检查受影响邻镜与依赖，不盲目全片重来。
- 交付验证文件、镜头清单、来源/许可、未解决项，等成片确认。保存不等于发布授权，不自动发布或改分享。

## 技能协作

本技能负责剧情、出处、连续性。栅格参考图调用现有图像生成能力；代码动画可用已安装 lemo-opuscar 等执行技能，但它们的默认配音、渲染、安装流程不得覆盖无旁白和阶段门。只改本项目资产，不改其他技能或用户已有文件。
